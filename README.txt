めぐろ財政ナビ ＡＩひろこ（デモ版）

【使い方】
このフォルダの index.html をダブルクリックしてください。
ブラウザ（Chrome / Safari / Edge）が開いて、すぐ会話できます。
インストールも設定も要りません。

【画面】
・左　　AIひろこ。答えの内容に合わせて表情が変わります
・右　　会話。下のボタンから質問を選ぶか、自由に入力できます
・「図を見る」　6種類のグラフを直接表示できます
・「音声 ON」　読み上げます（ブラウザの音声。声は選べません）
・「リセット」　会話を最初から

【この版でできること】
・目黒区の財政の健全度（全国1,690団体・23区との比較）
・吉田方式の首長バランスシート／市民バランスシート（将来の税金）
・図書館・住民票・プールの1回あたりの税金（当方の試算）
・なぜそう見せるのかという考え方（ICMAの業績測定の考え方）

【注意】
・デモ版です。数字は令和7年度決算がもとで、施設コストは仮定を置いた試算です。
・まだ誤った出典を書くことがあります。おかしな答えを見つけたら、
  そのまま送ってください（質問と答えのスクリーンショットで十分です）。
・このフォルダには接続用のキー（config.local.js）が入っています。
  一般公開の場には置かないでください。
